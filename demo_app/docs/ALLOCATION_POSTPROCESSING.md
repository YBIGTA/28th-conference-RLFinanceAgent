# 예상 매수 수량 후처리

이 문서는 PPO의 모델 출력과 데모 화면의 예상 주문 수량을 구분하고, 발표용 비례 배분 후처리의 목적과 한계를 설명함.

## 핵심 결론

PPO가 직접 출력하는 값은 50종목의 `action score`임. 화면의 예상 매수·매도 수량은 이 score에 현금, 보유량, 가격, 거래비용, 종목별 보유 상한을 적용한 별도 후처리 결과임.

따라서 다음 두 문장을 구분해야 함.

- 모델 판단: “가온전선, 대한항공, 삼성전자 등에 양수 action score를 출력함”
- 데모 후처리: “가용 현금을 양수 action score 비례로 나눠 예상 매수 수량을 계산함”

## 기존 순차 체결 방식

학습 환경과 기존 데모는 매도 신호를 먼저 처리한 뒤, 매수 신호를 고정 action index 순서로 처리함.

```text
첫 번째 매수 종목을 가능한 만큼 매수
→ 남은 현금으로 두 번째 종목 매수
→ 현금이 부족하면 이후 종목은 0주
```

예를 들어 현금 1,000만원, 가온전선 가격 331,500원, 거래비용 0.3%일 때 가온전선의 action이 `1.0`이면 최대 요청량은 500주임. 실제 현금으로는 30주를 먼저 구매하고 약 2.5만원만 남으므로 뒤의 매수 종목 대부분이 0주가 될 수 있음.

이 결과는 “모델이 가온전선에만 투자하기로 결정했다”는 뜻이 아님. 여러 종목에 매수 score를 출력했지만 수량 후처리가 앞 종목부터 현금을 소진한 결과임.

## 발표용 비례 배분 방식

현재 데모는 다음 순서로 예상 수량을 계산함.

1. 음수 action에 따른 예상 매도를 먼저 처리해 가용 현금을 계산함.
2. `score > 0.10`인 매수 후보를 선택함.
3. 각 종목의 최대 요청량을 `score × 500주`로 계산함.
4. 가용 현금을 양수 action score 비율로 나눔.
5. 종목별 가격과 거래비용 0.3%를 적용해 정수 주식 수를 계산함.
6. 남은 현금은 목표 비율보다 적게 배정된 종목에 추가 1주씩 배분함.
7. 기존 보유량을 포함해 종목당 500주 상한을 적용함.

동일한 가격의 세 종목이 모두 `1.0`이면 각 종목에 약 1/3씩 배분함. score가 `1.0`과 `0.5`이면 목표 매수 금액은 대략 2:1이 됨. 실제 수량은 종목 가격과 정수 주식 제약 때문에 정확히 같은 비율이 아닐 수 있음.

구현은 [`../backend/pipeline.py`](../backend/pipeline.py)의 `_allocate_proportional_buys()`에 있으며, 테스트는 [`../backend/test_pipeline.py`](../backend/test_pipeline.py)에 있음.

## 바뀌는 것과 바뀌지 않는 것

### 바뀌는 것

- 화면의 예상 매수 수량
- 예상 매수 금액
- 예상 잔여 현금
- 고정 ticker 순서에 따른 선착순 현금 소진

### 바뀌지 않는 것

- PPO 모델 가중치
- 1,467차원 입력 state
- 50차원 action score
- `±0.10` 매수·보유·매도 임계값
- 뉴스 임베딩과 Autoencoder 처리
- 실제 주문을 수행하지 않는 연구용 데모라는 성격

## 발표 시 권장 설명

다음과 같이 설명함.

> PPO는 고정 50종목에 대한 매매 방향과 강도를 action score로 출력합니다. 화면의 예상 수량은 모델 출력 자체가 아니라, 여러 매수 신호를 한 종목에 몰지 않도록 가용 현금을 양수 score 비례로 분산한 발표용 시뮬레이션 결과입니다.

다음 표현은 사용하지 않음.

- “모델이 이 수량을 직접 주문했다”
- “모델이 최적 포트폴리오 비중을 계산했다”
- “비례 배분 후 수량이 학습 당시 정책을 정확히 재현한다”
- “action score가 기대수익률이나 상승 확률이다”

## 한계와 향후 작업

현재 PPO는 순차 체결 방식의 환경에서 학습됐음. 따라서 데모의 비례 배분 예상 수량은 발표 화면의 종목 순서 편향을 줄이기 위한 후처리이며, 기존 학습·백테스트의 체결 과정을 그대로 재현하지 않음.

연구 결과까지 비례 배분 방식과 일치시키려면 다음 작업이 필요함.

1. 학습 환경의 매수 체결을 동일한 비례 배분 방식으로 변경함.
2. PPO를 처음부터 다시 학습함.
3. 독립 validation과 holdout 기간에서 다시 평가함.
4. 기존 순차 체결 모델과 수익률, 변동성, 회전율, 최대 낙폭을 비교함.

현재 발표에서는 “모델 score”와 “데모 예상 수량 후처리”를 분리해서 설명하는 것이 정확함.

# 발표자료 제작 가이드

이 문서는 RLFinanceAgent 모델과 데모 앱의 발표자료를 만드는 사람이 먼저 확인할 사실 기준표임. 슬라이드 문구는 이 문서를 기준으로 작성하고, 상세 설명과 발표 Q&A는 [`CONFERENCE_GUIDE.md`](CONFERENCE_GUIDE.md)를 참고함.

## 권장 문서 순서

1. [`SITE_OVERVIEW.md`](SITE_OVERVIEW.md): 비개발자 관점의 사이트 목적과 화면 구성
2. 이 문서: 슬라이드 구조, 검증된 수치, 표현상의 주의점
3. [`CONFERENCE_GUIDE.md`](CONFERENCE_GUIDE.md): 시연 순서, 종목 universe, 학습·추론 상세, 예상 질문
4. [`../../README.md`](../../README.md): 환경, reward, 데이터 기간 등 구현 세부사항
5. [`../DEPLOYMENT.md`](../DEPLOYMENT.md): 시연 운영자만 확인할 배포·비밀번호 설정

## 한 문장 소개

KOSPI 고정 50종목의 가격·기술지표·뉴스 표현을 하나의 상태로 결합하고, PPO 정책이 종목별 매수·보유·매도 강도를 동시에 출력하는 연구용 투자 에이전트 데모임.

## 발표에 사용할 핵심 수치

### State와 Action

| 구성 | 차원 |
|---|---:|
| 현금 잔고 | 1 |
| 50종목 보유 수량 | 50 |
| 50종목 가격 | 50 |
| 11개 기술지표 × 50종목 | 550 |
| 종목 뉴스 16차원 × 50종목 | 800 |
| 시장 뉴스 16차원 | 16 |
| State 합계 | 1,467 |
| PPO Action | 50 |

Action은 종목별 `[-1, 1]` 연속값임. 데모는 `0.10` 초과를 매수, `-0.10` 미만을 매도, 그 사이를 보유로 표시함. 이 값은 확률, 예상수익률, 신뢰도가 아님.

### 모델 구조

- 뉴스: Upstage `embedding-passage` 4,096차원 → 공용 Autoencoder `4096 → 1024 → 256 → 64 → 16`
- PPO Actor: `1467 → 256 → 256 → 50`, 은닉층 Tanh
- PPO Critic: `1467 → 256 → 256 → 1`, 은닉층 Tanh
- Actor와 Critic의 MLP 가중치는 분리됨
- 데모 추론은 `deterministic=True`로 action mean을 사용함

### 학습 설정과 기간

| 항목 | 값 |
|---|---:|
| 학습 기간 | 2025년 |
| 테스트 기간 | 2026-01-01 ~ 2026-05-18 |
| 총 학습 timestep | 2,000,000 |
| learning rate | 0.0003 |
| `n_steps` | 2,048 |
| batch size | 64 |
| gamma | 0.99 |
| clip range | 0.20 |

저장된 best model은 학습 환경 평가값으로 선택됐으며 독립 validation set으로 선정된 모델이 아님. 테스트 기간은 학습 이후 구간이지만, 현재 데모는 검증된 실거래 수익성을 주장하는 제품이 아님.

## 실행 모드 비교

| 구분 | 샘플 모드 | 최신 데이터 모드 |
|---|---|---|
| 입력 | 모델 ZIP에 저장된 실제 관측값 | 최신 완료 거래일의 가격·뉴스 |
| 외부 요청 | 없음 | Yahoo Finance, 네이버, Upstage |
| 결과 재현성 | 같은 입력이면 동일 | 날짜·기사·외부 응답에 따라 변경 |
| 예상 시간 | warm 1~3초, cold start 15~30초 | 보통 1~3분, 캐시 사용 시 단축 |
| 발표 역할 | 먼저 성공을 보여주는 안전한 시연 | 실제 데이터 파이프라인 시연 |

최신 뉴스는 긍정·부정을 직접 분류하지 않음. 기사 의미를 4,096차원 임베딩으로 표현하고 Autoencoder로 16차원에 압축해 상태에 포함함. 따라서 이를 단일한 “시장 심리 점수”라고 설명하면 부정확함.

## 종목 선정과 결과 해석

- 데모의 50종목은 실행할 때마다 새로 선정되는 종목이 아니라 해당 PPO 체크포인트가 학습한 고정 universe임.
- 저장소에는 최초 universe를 만든 시가총액·유동성 스크리닝 근거가 남아 있지 않음.
- PPO는 고정 50종목 각각에 action score를 출력함.
- 화면의 예상 주문 수량은 action score에 현금, 현재 보유량, 종목별 최대 500주, 거래비용 0.3%를 적용한 시뮬레이션 값임.
- 실제 주문을 전송하지 않으며 투자 권유 서비스가 아님.

## 사용하면 안 되는 표현

- “모델이 KOSPI 전체에서 최적의 50종목을 골랐다”
- “시가총액 상위 50종목이다” 또는 “유동성 상위 50종목이다”
- “action score는 상승 확률·확신도·예상수익률이다”
- “뉴스 감성을 긍정·부정 점수로 분석한다”
- “독립 검증으로 수익성이 입증됐다”
- “각 추천의 원인을 종목별로 인과적으로 설명할 수 있다”
- “실제 매매 주문을 실행한다”

권장 표현은 “고정 50종목을 대상으로 가격·기술지표·압축된 뉴스 표현을 입력받아, 학습된 PPO 정책이 종목별 연속 action을 출력한다”임.

## 시연 체크리스트

1. 시연 전에 배포 URL, 공유 비밀번호, 샘플 모드 성공 여부를 확인함.
2. 샘플 모드로 50종목 결과가 빠르게 생성되는 것을 먼저 보여줌.
3. State 구성과 action threshold를 설명함.
4. 최신 데이터 모드를 실행하고 Yahoo·네이버·Upstage 처리 단계를 보여줌.
5. 최신 모드는 최대 3분을 예상하고, 지연되면 샘플 결과와 파이프라인 이미지로 설명을 이어감.
6. 결과는 연구용 정책 출력이며 투자 권유나 수익 보장이 아님을 명시함.

배포 URL과 비밀번호는 공개 슬라이드에 적지 않고 발표자 노트나 별도 운영 문서로 전달함.
